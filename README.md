# Lithology prediction
Prediction of missed well logs/ Lithology prediction

**Background**
При построении геологической модели месторождения ключевым источником данных служит каротаж скважин (well logs) — геофизические измерения физических свойств горных пород вдоль ствола скважины. На основе этих измерений определяется литология (тип горных пород), которая задаёт набор петрофизических свойств, необходимых для оценки коллектора.

В качестве рабочего набора данных используется открытый датасет FORCE 2020 (каротаж по ~118 скважинам Северного моря). В рамках данного датасета возможно решение нескольких задач:
1. Восстановление пропущенных логов скважин (импутация)
2. Литологическая интерпретация: предсказание литологии по логам скважин

Сейчас и восстановление недостающих логов, и литологическая интерпретация выполняются экспертами в ручном/полуавтоматическом режиме, что трудозатратно и слабо масштабируется. Необходимо разработать ML-решение, которое позволит автоматизировать этот процесс.

**Task**
В рамках направления необходимо выполнить следующий ряд задач:
1. **Анализ предметной области**, ресёрч существующих решений и EDA датасета FORCE 2020: карта пропусков по скважинам и логам, корреляции между логами, распределение классов литологии.
2. **Восстановление пропущенных каротажных данных.** Разработать модель восстановления недостающих логов с разделением двух режимов: точечное восстановление пропусков в рамках одной скважины и реконструкция целиком отсутствующих кривых по физически коррелирующим логам. В качестве бейслайна предлагается использовать модели классического машинного обучения и провести анализ возможности и необходимости использования более сложных нейросетевых архитектур. 
3. **Предсказание литологии.** Разработать модель многоклассовой классификации литологии по каротажным признакам.  
4. **Анализ связи двух задач**: оценить, как качество восстановления логов влияет на точность классификации литологии, и предложить итоговый сквозной пайплайн «импутация -> классификация».
